# Safwa Quran — Quran content proof gate (source first, no features)

## Target Quran rendition
Tanzil Project Quran Text **Uthmani v1.1** (Hafs narration; aligned to
Medina Mushaf) is the chosen *source candidate*. These are the official
documentation references:

- https://tanzil.net/docs/medina_mushaf
- https://tanzil.net/docs/tanzil_project
- https://tanzil.net/download/
- https://tanzil.net/docs/version_1.1_updates
- https://tanzil.net/docs/Text_License
- https://tanzil.net/docs/me_quran_font

Tanzil describes rigorous manual and automatic source verification. That is
a statement by Tanzil, not an independent scholarly approval of this app.

- All **6,236 of 6,236** OFF verse strings match the pinned source verbatim.
- ON differs on 3,518 verses exclusively through insertions of U+06ED

- The 308 remaining differences against a *separate secondary source mirror*
  are a different comparison. They do not invalidate the exact OFF match,
  but their edition origin/options must not be guessed.

A file's SHA-256 is a digest of *all bytes* including copyright headers.
The OFF and pinned files may therefore have different whole-file SHA-256
while their 6,236 indexed verse strings agree exactly. This distinction
must be preserved.

## Reproducible exact-string content digest

The script `scripts/prove_quran_content.py` provides a SHA-256 digest of the
ordered `surah|ayah|verbatim_verse` rows using a UTF-8 LF terminator,
**without normalizing, adding, or removing Arabic characters**. It reports
identical derived verse-content digests only when the entire 6,236-verse
OFF download agrees with the pinned copy.

Example for the existing preserved OFF file:

```bash
cd ~/Safwa-Quran
python3 scripts/prove_quran_content.py \
  --off "$HOME/Downloads/quran-uthmani (1).txt" \
  --expected-off-sha256 7f30c647331a61100ebf24a80507dc0fcdd9f2df97f1312b5b2dfcb982a7f326 \
  --marks unknown --sajdah unknown --rub unknown \
  --tatweel unknown --stanween off
```

Store the generated `.staging/quran_content_proof.json` privately.
Never activate the reader based only on this report.

## Four remaining proof requirements

1. **Authentic download provenance and settings:** Retain direct source page,
   exact Uthmani text type, version, format, timestamp, complete original
   checkbox states, URL or browser network metadata, both untouched files and
   hashes. The current logs mark four shared option values unknown and the
   source origin unauthenticated. Filename similarity and text match alone
   cannot independently authenticate the downloaded file.
2. **Independent qualified review one:** A named, verifiably qualified Quran
   specialist independently compares the *entire intended text* and relevant
   marks to the Hafs Medina Mushaf reference, including sensitive typography,
   basmalah rules, surah order, verse boundaries, diacritics, orthography and
   pause/sajdah signs. Record scope, source digest, dated evidence, findings,
   qualifications, and authenticated sign-off.
3. **Independent qualified review two:** A **different** qualified specialist
   independently repeats the review against the exact same digest, without
   copying reviewer one's assessment. Any divergence remains open until
   documented resolution and new review.
4. **Exact rendition and rendering:** On real devices, visually inspect the
   intended Arabic font's shaping of all Quranic marks, ligatures, RTL order,
   basmalah, and representative long/short surahs. Especially assess
   sequential-tanween extra meems if those marks are enabled. Do not silently
   transform Quran text to fix display problems.
